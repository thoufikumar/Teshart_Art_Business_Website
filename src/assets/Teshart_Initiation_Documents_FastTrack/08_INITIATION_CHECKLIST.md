## Initiation exit criteria
The project can move into implementation when:
1. UX flow is frozen.
2. V1 scope is frozen.
3. Business pricing/payment/refund rules are defined.
4. Technical stack is accepted.
5. Database model is accepted.
6. Privacy expectations for customer photos are accepted.
7. SEO page strategy is accepted.
8. Antigravity project rules are installed.
